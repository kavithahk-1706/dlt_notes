31. Explain the concept of Greedy Layer-wise Pre-training. Discuss its role in training deep neural networks.

Greedy layer-wise pre-training trains a deep network one layer at a time with an unsupervised objective, and only then fine-tunes the whole network with labels. It is "greedy" because each layer is optimised on its own instead of jointly.

Steps

  1. Layer 1: treat \(x\to h_1\to\hat x\) as an autoencoder and train it to reconstruct the input: \(\ \min\ \frac{1}{m}\sum_{i=1}^{m}\sum_{j=1}^{n}(\hat x_{ij}-x_{ij})^2\).
  2. Layer 2: fix layer 1, and train \(h_1\to h_2\to\hat h_1\) to reconstruct \(h_1\): \(\ \min\ \frac{1}{m}\sum_{i=1}^{m}\sum_{j}(\hat h_{1,ij}-h_{1,ij})^2\).
  3. Continue the same way until the last hidden layer.
  4. Fine-tuning: add the output layer and train all layers together on the supervised loss: \(\ \min_{\theta}\ \frac{1}{m}\sum_{i=1}^{m}\bigl(y_i-f(x_i)\bigr)^2\).

Why it helps in training deep networks

ViewExplanation
Better initialisationThe pre-trained weights start the supervised search in a good region of the highly non-convex error surface, instead of a random point.
OptimisationHelps most when the network has limited capacity; with a very large last layer the supervised loss can reach 0 even without pre-training.
RegularisationThe unsupervised objective acts as an extra constraint \(\Omega(\theta)\), keeping weights in regions that capture the characteristics of the data, so learning is less greedy with respect to the labelled loss.

Role today: it made deep networks trainable before better activations (ReLU), initialisation and Batch Normalisation (Q32, Q34, Q36) existed. These now largely remove the need for it, but it remains useful when labelled data is scarce and unlabelled data is plentiful.

Worked example — a 784–256–64–10 network

StageWhat is trainedDataReconstruction target
1autoencoder \(784\to256\to784\)unlabelled images \(x\)\(x\)
2autoencoder \(256\to64\to256\) (layer 1 fixed)\(h_1\) from stage 1\(h_1\)
3softmax layer \(64\to10\) added; all layers fine-tunedsmall labelled set \((x,y)\)label \(y\)

Stages 1–2 can use a very large pool of unlabelled data; only stage 3 needs labels. That is the practical value: when labelled data is scarce, the lower layers have already learned features of the inputs, so fine-tuning starts from a sensible point rather than from random weights.

Why "greedy": each layer is trained to be good by itself (it only reconstructs its own input), without knowing what the final task is. Fine-tuning then adjusts all layers together to fit the task.

32. Explain the concept of activation functions. Discuss the commonly used activation functions and their advantages.

What is an Activation Function?

In a feedforward neural network, the pre-activation at layer \(i\) is \(a_i = b_i + W_i h_{i-1}\), and the activation is \(h_i = g(a_i)\), where \(g\) is the activation function. It introduces non-linearity, which allows the network to learn complex decision boundaries. Without an activation function (or with a linear one), the entire network collapses into a single linear transformation regardless of depth.

1. Sigmoid (Logistic)

\[\sigma(a) = \frac{1}{1 + e^{-a}} \qquad \text{Range: } (0, 1)\]

Advantages: Smooth, differentiable, outputs can be interpreted as probabilities. Disadvantages: (i) Outputs are not zero-centred. (ii) Saturates for large \(|a|\), causing vanishing gradients — since \(\sigma'(a) = \sigma(a)(1 - \sigma(a))\), the gradient \(\to 0\) when \(a\) is very large or very small. (iii) Involves exponential computation.

2. Tanh (Hyperbolic Tangent)

\[\tanh(a) = \frac{e^a - e^{-a}}{e^a + e^{-a}} \qquad \text{Range: } (-1, 1)\]

This is a scaled and shifted sigmoid: \(\tanh(a) = 2\sigma(2a) - 1\). Advantages: Zero-centred outputs, which helps gradient-based learning converge faster. Disadvantages: Still saturates for large \(|a|\) (vanishing gradient issue persists).

3. ReLU (Rectified Linear Unit)

\[\text{ReLU}(a) = \max(0, a) \qquad \text{Range: } [0, \infty)\]

Advantages: (i) Does not saturate in the positive region — gradient is always 1 for \(a > 0\), which accelerates convergence significantly over sigmoid/tanh. (ii) Computationally efficient (just a threshold). (iii) Leads to sparse activations (many neurons output 0). Disadvantages: Dying ReLU problem — if \(a < 0\), gradient is 0, and the neuron may never activate again (especially with large learning rates). Not zero-centred.

4. Leaky ReLU

\[\text{LeakyReLU}(a) = \begin{cases} a & \text{if } a > 0 \\ \alpha \, a & \text{if } a \leq 0 \end{cases} \qquad \alpha \approx 0.01\]

Addresses the dying ReLU problem by allowing a small non-zero gradient (\(\alpha\)) for negative inputs. The neuron never fully dies.

5. Parametric ReLU (PReLU)

\[\text{PReLU}(a) = \max(0, a) + \alpha \cdot \min(0, a)\]

Same as Leaky ReLU, but \(\alpha\) is a learnable parameter that is updated via backpropagation. This allows the network to adaptively determine the optimal slope for negative values.

Summary of Choice

In practice, ReLU is the default choice for hidden layers (much faster convergence than sigmoid/tanh). If dying neurons are a concern, use Leaky ReLU or PReLU. Sigmoid is primarily used at the output layer for binary classification, and softmax for multi-class classification.

33. Differentiate between linear and non-linear activation functions. Why are non-linear activation functions preferred in deep learning?

An activation function \(g\) turns the pre-activation \(a_i=b_i+W_ih_{i-1}\) into the layer output \(h_i=g(a_i)\). It is either linear or non-linear.

Linear activation

\(g(a)=a\) (or \(ca\)). A stack of linear layers is still one linear map:

\[\hat y=W_L\bigl(\cdots W_2(W_1x+b_1)+b_2\cdots\bigr)+b_L=W'x+b'\]

So however deep the network, it can only represent a linear function and draws only a straight decision boundary. It cannot even represent XOR (Q3, Q4).

Non-linear activation

Sigmoid, tanh, ReLU, Leaky ReLU, etc. Because \(g\) is non-linear, each layer re-shapes the space, so stacking layers builds up progressively more complex functions.

Comparison

LinearNon-linear
Form\(g(a)=a\)\(\sigma(a),\ \tanh(a),\ \max(0,a),\dots\)
Effect of depthLayers collapse into oneEach extra layer adds representational power
Decision boundaryStraight line / hyperplaneCurved, arbitrarily complex
Derivative \(g'(a)\)Constant — gives no information about the inputDepends on \(a\), so backpropagation can assign credit differently to each unit
Typical useOutput layer of regression; linear decoder of an autoencoderHidden layers

Why non-linear activations are preferred

  • Expressiveness: they make depth meaningful; with them a network can represent XOR and any boolean function (Q4).
  • Universal approximation: one hidden layer of non-linear sigmoid units can approximate any continuous function to any desired precision.
  • Real data is non-linear (images, speech, text), so linear models underfit.
  • They must also be differentiable (for backpropagation) and ideally non-saturating and zero-centred — hence ReLU-type units (Q32).

Worked example — linear layers collapse, non-linear ones do not

Let \(W_1=\begin{bmatrix}1&-2\\0&1\end{bmatrix}\), \(W_2=\begin{bmatrix}1&-1\end{bmatrix}\), biases 0, input \(x=(1,2)^T\).

Linear (no activation)\(W_1x=(-3,2)\), then \(W_2(-3,2)=-3-2\)\(-5\)
Same, collapsed\(W_2W_1=\begin{bmatrix}1&-3\end{bmatrix}\), so \(W_2W_1x=1-6\)\(-5\) (identical)
With ReLU after layer 1\(\mathrm{ReLU}(-3,2)=(0,2)\), then \(0-2\)\(-2\)

The two linear computations agree exactly, so the extra layer added nothing. The ReLU network gives a different answer that no single linear map reproduces for all inputs — it has really used its second layer.

34. What is weight initialization? Discuss the commonly used weight initialization methods in deep learning.

Why Weight Initialization Matters

Training deep neural networks is a game of gradients. The gradient with respect to a parameter is proportional to the input to that parameter. If weights are initialized poorly, the activations at each layer can either explode (grow exponentially) or vanish (shrink to near zero), making learning impossible. Good initialization ensures that the variance of activations and gradients remains stable across layers.

Naive Initialization (Problems)

All zeros: Every neuron computes the same output; gradients are identical; the network cannot break symmetry. Small random values (e.g., \(\mathcal{N}(0, 0.01)\)): Works for shallow networks, but in deep networks the activations shrink exponentially layer by layer (variance collapses), leading to vanishing gradients. Large random values: Activations saturate (for sigmoid/tanh), gradients vanish again.

Xavier / Glorot Initialization

Designed for networks using sigmoid or tanh activations (symmetric, approximately linear near zero). The key insight is to keep the variance of activations the same across layers.

\[W \sim \mathcal{N}\left(0, \; \frac{2}{n_{\text{in}} + n_{\text{out}}}\right)\]

Alternatively, using a uniform distribution:

\[W \sim \mathcal{U}\left(-\sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}}, \; \sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}}\right)\]

Here \(n_{\text{in}}\) is the number of input neurons (fan-in) and \(n_{\text{out}}\) is the number of output neurons (fan-out) of the layer. This ensures \(\text{Var}(h_i) \approx \text{Var}(h_{i-1})\) — i.e., the signal neither amplifies nor decays.

He (Kaiming) Initialization

Designed for networks using ReLU activations. Since ReLU sets all negative inputs to zero, half the neurons are inactive on average. He initialization compensates for this by using a larger variance:

\[W \sim \mathcal{N}\left(0, \; \frac{2}{n_{\text{in}}}\right)\]

The factor of 2 (instead of 1) accounts for the fact that ReLU zeros out approximately half the activations. This maintains stable activation magnitudes throughout deep ReLU networks.

Summary

MethodVarianceBest For
Xavier / Glorot\(\frac{2}{n_{\text{in}} + n_{\text{out}}}\)Sigmoid, Tanh
He / Kaiming\(\frac{2}{n_{\text{in}}}\)ReLU and variants

Modern deep learning frameworks typically default to He initialization for ReLU networks. When using batch normalisation, the sensitivity to initialisation is reduced, but proper initialisation still provides faster convergence.

35. Why is weight initialization important in deep learning? Explain the problems caused by poor weight initialization.

Training a deep network is a game of gradients: the gradient of a weight is proportional to the input that weight sees. If the initial weights are badly chosen, the signal and the gradients either die or blow up as they pass through the layers, and learning stalls.

Problems caused by poor initialisation

InitialisationWhat goes wrong
All zeros / constant\(a_{11}=a_{12}=0\Rightarrow h_{11}=h_{12}\Rightarrow\nabla w_{11}=\nabla w_{21}\). Neurons in a layer stay identical forever (symmetry is never broken), so they all learn the same feature.
Large random weights (sigmoid / tanh)Pre-activations are large, the units saturate at 0 or 1, \(\sigma'\approx0\), and gradients vanish.
Small random weights (tanh)Activations shrink towards 0 layer after layer; since weight gradients are proportional to the incoming activations, they vanish too.
Variance too large in deep netsSignals and gradients grow exponentially with depth (exploding).

The variance argument

Assume zero-mean inputs and weights. For a unit with \(n\) inputs, \(s_{11}=\sum_{i=1}^{n}w_{1i}x_i\), so

\[\mathrm{Var}(s_{11})=\sum_{i=1}^{n}\mathrm{Var}(w_{1i}x_i)=n\,\mathrm{Var}(w)\,\mathrm{Var}(x),\qquad \mathrm{Var}(s_{k})=\bigl[n\,\mathrm{Var}(w)\bigr]^{k}\,\mathrm{Var}(x)\]

Over \(k\) layers the variance is multiplied by \(n\,\mathrm{Var}(w)\) each time: if this is below 1 the signal vanishes, above 1 it explodes. We therefore want \(n\,\mathrm{Var}(w)=1\).

Remedy

  • Draw weights from a unit Gaussian and scale by \(1/\sqrt n\): \(\ w=z/\sqrt n\), so \(n\,\mathrm{Var}(w)=1\) (Xavier-type scaling).
  • For ReLU use an extra factor of 2 (He initialisation), because ReLU keeps only the positive half of its inputs (details in Q34).
  • Use small random values to break symmetry, never zeros; for ReLU units a small positive bias (e.g. 0.01) helps avoid dead units.

Worked example — effect of \(n\,\mathrm{Var}(w)\) over 10 layers

Layers have \(n=100\) inputs. The variance of the pre-activation is multiplied by \(n\,\mathrm{Var}(w)\) at each layer:

\(\mathrm{Var}(w)\)\(n\,\mathrm{Var}(w)\)Factor after 10 layersResult
0.0050.5\(0.5^{10}\approx0.001\)signal vanishes
0.0111stable
0.022\(2^{10}=1024\)explodes (standard deviation ×32)

A mere factor of 2 in the weight variance is enough to change the signal by a factor of 1000 over only ten layers. For ReLU, half of the units output 0, so the variance is halved at every layer; to compensate, take \(\mathrm{Var}(w)=2/n\) (He initialisation).

Why zero initialisation fails — tiny example

Two hidden units with identical incoming weights give \(h_1=h_2\) for every input. The error reaching them is the same, so \(\nabla w_{1}=\nabla w_{2}\) and after the update they are still identical. Two (or 1000) neurons behave as one, and the layer's capacity is wasted. Random initialisation breaks this symmetry.

36. Explain Batch Normalization. What are its advantages in training deep neural networks?

Batch Normalisation (BN) keeps the pre-activations of every layer well-behaved during training by standardising them, so that a layer's input does not keep shifting as the weights below it change. It was introduced to make very deep networks easier to train.

Idea

Unit-Gaussian pre-activations avoid both saturation (Q35) and vanishing/exploding signals. So instead of only hoping for this through initialisation, we force it: take the pre-activation \(s_{ik}\) of the \(k\)-th unit in layer \(i\) and standardise it:

\[\hat s_{ik}=\frac{s_{ik}-E[s_{ik}]}{\sqrt{\mathrm{Var}[s_{ik}]}}\]

This is a differentiable operation, so it can sit inside the network and gradients flow through it during backpropagation. \(E\) and \(\mathrm{Var}\) are estimated on the current mini-batch of \(m\) examples:

\[\mu_B=\frac1m\sum_{j=1}^{m}s_{ik}^{(j)},\qquad \sigma_B^2=\frac1m\sum_{j=1}^{m}\bigl(s_{ik}^{(j)}-\mu_B\bigr)^2,\qquad \hat s^{(j)}_{ik}=\frac{s^{(j)}_{ik}-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}\]

(\(\epsilon\) is a tiny constant that avoids division by zero.)

Restoring representational power

Forcing every unit to have mean 0 and variance 1 may be too restrictive, so BN adds two learnable parameters per unit, a scale \(\gamma\) and a shift \(\beta\):

\[y_{ik}=\gamma_k\,\hat s_{ik}+\beta_k\]

The network can learn \(\gamma_k=\sqrt{\mathrm{Var}[s_{ik}]}\) and \(\beta_k=E[s_{ik}]\), which would undo the normalisation if that turns out best. \(\gamma,\beta\) are updated by gradient descent like any other parameter. The layer then becomes \(h_i=g(y_i)\).

Where it is used and at test time

  • It is inserted before the non-linearity of each layer (after \(a_i=W_ih_{i-1}+b_i\), before \(g\)).
  • At test time there may be no mini-batch, so a running average of \(\mu_B\) and \(\sigma_B^2\) collected during training is used (standard practice, an addition to the slide treatment).

Advantages

AdvantageWhy
Faster trainingStable activation scale lets us use much larger learning rates.
Reduces vanishing/exploding gradientsPre-activations stay in the sensitive region of sigmoid/tanh and in a sensible range for ReLU.
Less sensitive to initialisationWhatever the starting weights, each layer's output is re-standardised.
Mild regularisationThe mini-batch statistics add noise to each example, sometimes reducing the need for dropout.
Fewer training epochsConverges in far fewer steps to the same accuracy.
Source: CS7015 Lecture 9 (Khapra) — batch normalisation (\(\hat s_{ik}\), \(\gamma\), \(\beta\)). The \(\mu_B,\sigma_B^2,\epsilon\), running-average form is the standard version and is added for completeness.

37. What is Word2Vec? Describe how Word2Vec generates word embeddings.

Motivation

Traditional representations like one-hot vectors encode each word as a sparse vector of size \(|V|\) (vocabulary size), where only the \(i\)-th element is 1. This representation has two problems: (i) it is very high-dimensional (\(|V|\) can be \(10^5\)+), and (ii) it captures no semantic similarity — the dot product between any two one-hot vectors is 0.

Word2Vec (Mikolov et al., 2013) is a method that learns dense, low-dimensional vector representations of words (called word embeddings) such that semantically similar words have similar vectors. The core idea comes from the distributional hypothesis: a word's meaning is captured by the words that frequently appear near it.

Architecture 1: Continuous Bag of Words (CBOW)

CBOW predicts a target (centre) word given its surrounding context words. Given a window of size \(c\) around the target word \(w_t\), the model maximises:

\[\frac{1}{T}\sum_{t=1}^{T} \log P(w_t \mid w_{t-c}, \ldots, w_{t-1}, w_{t+1}, \ldots, w_{t+c})\]

The context word vectors are averaged and passed through a hidden layer (no activation), and then a softmax output layer predicts the probability over the vocabulary. The hidden layer weights give the word embeddings.

Architecture 2: Skip-gram

Skip-gram does the opposite — it predicts the context words given a single input (centre) word. It maximises:

\[\frac{1}{T}\sum_{t=1}^{T} \sum_{-c \leq j \leq c, \; j \neq 0} \log P(w_{t+j} \mid w_t)\]

The probability is computed using softmax:

\[P(w_O \mid w_I) = \frac{\exp(\mathbf{u}_{w_O}^T \mathbf{v}_{w_I})}{\sum_{w=1}^{|V|} \exp(\mathbf{u}_{w}^T \mathbf{v}_{w_I})}\]

Here \(\mathbf{v}_{w_I}\) is the input vector of the centre word and \(\mathbf{u}_{w_O}\) is the output vector of the context word. There are two embedding matrices — one for input and one for output. Typically, the input matrix is used as the final word embeddings.

Negative Sampling

Computing the full softmax over \(|V|\) words is expensive. Negative sampling approximates it by training the model to distinguish the true context word from \(k\) randomly sampled "negative" (non-context) words. The objective for a pair \((w_I, w_O)\) becomes:

\[\log \sigma(\mathbf{u}_{w_O}^T \mathbf{v}_{w_I}) + \sum_{i=1}^{k} \mathbb{E}_{w_i \sim P_n(w)} \left[\log \sigma(-\mathbf{u}_{w_i}^T \mathbf{v}_{w_I})\right]\]

Negative words are sampled from a noise distribution \(P_n(w) \propto f(w)^{3/4}\), where \(f(w)\) is the word frequency.

Key Properties of Word2Vec Embeddings

The learned vectors exhibit semantic regularities. For example, vector arithmetic captures analogies: \(\mathbf{v}_{\text{king}} - \mathbf{v}_{\text{man}} + \mathbf{v}_{\text{woman}} \approx \mathbf{v}_{\text{queen}}\). Similarity between words is measured by cosine similarity between their embedding vectors.

38. What is object detection in computer vision? Discuss its applications.

Object detection is the task of finding what objects are in an image and where they are. For every object of interest, the model outputs a class label together with a bounding box, and an image can contain any number of objects of different classes.

How it differs from related tasks

TaskOutputObjects per image
ClassificationOne label for the whole image: \(\hat y\in\{1,\dots,K\}\)Assumes one main object
LocalisationLabel + one box \((x,y,w,h)\)Exactly one
DetectionA set of \((\text{label},\ x,y,w,h)\) tuplesVariable (0, 1 or many)

Output and training loss

A box is described by its centre, width and height, \((b_x,b_y,b_w,b_h)\). The network predicts a class distribution and a box for each candidate, and is trained on a combined loss:

\[L=L_{\text{cls}}+\lambda\,L_{\text{box}},\qquad L_{\text{cls}}=-\sum_{k}y_k\log\hat y_k,\qquad L_{\text{box}}=\sum_{j\in\{x,y,w,h\}}(b_j-\hat b_j)^2\]

Measuring a detection — IoU

A predicted box is judged by how much it overlaps the ground-truth box:

\[\mathrm{IoU}=\frac{\text{area}(B_{\text{pred}}\cap B_{\text{gt}})}{\text{area}(B_{\text{pred}}\cup B_{\text{gt}})}\in[0,1]\]

A detection is usually counted as correct when IoU \(\ge 0.5\). Overlapping duplicate boxes for the same object are removed by non-maximum suppression (keep the highest-scoring box, drop boxes with high IoU with it).

Main approaches (details in Q39)

  • Region-proposal based (two-stage): R-CNN → Fast R-CNN → Faster R-CNN.
  • Single-shot (one-stage): YOLO, SSD — predict boxes and classes in one pass; faster.

39. Describe the process of object detection in images and videos using deep learning.

Object Detection vs. Classification

Image classification assigns a single label to the entire image. Object detection goes further: it must (i) localise one or more objects in the image by drawing bounding boxes around them, and (ii) classify each detected object.

R-CNN (Regions with CNN features)

The first major deep-learning-based object detection pipeline (Girshick et al., 2014):

  1. Region proposals: Use a method like Selective Search to generate ~2000 candidate bounding box regions.
  2. Feature extraction: Warp each region to a fixed size and pass it through a CNN (e.g., AlexNet) to extract a feature vector.
  3. Classification: Feed the feature vector into SVMs (one per class) to classify the region.
  4. Bounding box regression: Refine the bounding box coordinates using a linear regressor.

Limitation: Very slow — each region proposal requires a separate forward pass through the CNN.

Fast R-CNN

Runs the CNN on the entire image once to produce a shared feature map. Region proposals are then projected onto this feature map, and RoI (Region of Interest) pooling extracts a fixed-size feature vector for each region. A single network jointly performs classification and bounding box regression. This is significantly faster than R-CNN.

Faster R-CNN

Replaces Selective Search with a Region Proposal Network (RPN) — a small CNN that slides over the feature map and predicts whether each location contains an object, along with a bounding box. The RPN and the detection network share the same convolutional feature map, making the entire pipeline end-to-end trainable and much faster.

YOLO (You Only Look Once)

A fundamentally different approach — treats object detection as a single regression problem. The image is divided into an \(S \times S\) grid. Each grid cell predicts \(B\) bounding boxes (each with coordinates and a confidence score) and class probabilities simultaneously, in a single forward pass.

Advantages: Extremely fast — capable of real-time detection. Trade-off: May be less accurate on small or overlapping objects compared to two-stage methods like Faster R-CNN.

Extension to Video

For video, object detection is applied frame-by-frame. Temporal consistency is maintained through tracking algorithms or by using 3D CNNs / temporal attention that consider sequences of frames.

40. How is user history used to generate product or content recommendations? Discuss its applications.

Recommendations Using Deep Learning

Recommendation systems aim to predict a user's preference for items (products, movies, songs, etc.) based on their past interactions. Deep learning enables learning complex, non-linear relationships between users and items from large-scale interaction data.

User History as Input

A user's history is a sequence of past interactions — items viewed, clicked, purchased, rated, or time spent. This history is fed to the model as input features. Common representations include:

  • Embeddings: Each item in the user's history is mapped to a dense vector (similar to word embeddings in Word2Vec). The user's history becomes a sequence of embedding vectors.
  • Aggregated profile: The item embeddings are averaged or pooled to create a single user-profile vector.
  • Sequential models: RNNs or Transformers process the ordered history to capture temporal patterns (e.g., what a user is likely to want next based on their recent activity).
\[e_u=\frac{1}{|H_u|}\sum_{i\in H_u}e_i\qquad\text{(pooled profile of the items in history }H_u\text{)}\]
\[h_t=\mathrm{RNN}(h_{t-1},e_{i_t}),\qquad P(\text{next}=j)=\mathrm{softmax}(Wh_t+b)_j\qquad\text{(sequential model)}\]

The item embeddings can be learned exactly like word embeddings (Q37): treat the items a user interacted with in one session as the "words" of a sentence and train skip-gram, so that items bought or watched together end up close in the embedding space.

Collaborative Filtering with Deep Learning

In matrix factorisation approaches, users and items are each represented as latent vectors. The predicted rating is the dot product of the user and item vectors. Deep learning extends this by passing the concatenated user and item embeddings through a feedforward network to capture non-linear interactions:

\[\hat{r}_{ui} = f_\theta(\mathbf{e}_u, \mathbf{e}_i)\]

where \(\mathbf{e}_u\) is the user embedding, \(\mathbf{e}_i\) is the item embedding, and \(f_\theta\) is a neural network.

The simplest collaborative model is matrix factorisation, \(\hat r_{ui}=\mathbf e_u^{T}\mathbf e_i\); the network \(f_\theta\) above replaces the dot product with learned layers.

Training from History

Explicit feedback (ratings \(r_{ui}\)): minimise squared error over observed pairs \(\mathcal O\) with regularisation:

\[\mathcal L=\sum_{(u,i)\in\mathcal O}\bigl(r_{ui}-\hat r_{ui}\bigr)^2+\lambda\bigl(\|\mathbf e_u\|^2+\|\mathbf e_i\|^2\bigr)\]

Implicit feedback (clicks, purchases, watch time): an interaction is a positive example \(y_{ui}=1\); items the user did not interact with are sampled as negatives (\(y_{ui}=0\)). With \(\hat y_{ui}=\sigma\bigl(f_\theta(\mathbf e_u,\mathbf e_i)\bigr)\):

\[\mathcal L=-\sum_{(u,i)}\Bigl[y_{ui}\log\hat y_{ui}+(1-y_{ui})\log\bigl(1-\hat y_{ui}\bigr)\Bigr]\]

Both are trained with backpropagation, and the user/item embeddings are learned together with the network.

Content-Based Filtering with Deep Features

CNNs and RNNs can extract features from the content itself — images (CNN features from product photos), text (RNN/Transformer features from reviews or descriptions). These content features are combined with collaborative signals to improve recommendations, especially for new items with no interaction history (cold-start problem).

Generating the Recommendation and Evaluating It

  • Candidate generation: a fast model narrows millions of items to a few hundred using the user vector.
  • Ranking: a heavier network scores each candidate and the top-\(K\) are shown, excluding items already seen.
  • Metrics: \(\text{Precision@}K=\dfrac{|\text{relevant}\cap\text{top-}K|}{K}\), \(\ \text{Recall@}K=\dfrac{|\text{relevant}\cap\text{top-}K|}{|\text{relevant}|}\); for ratings, RMSE.

Challenges: cold start (new users or items with no history), sparse interactions, popularity bias, privacy of the stored history, and feedback loops (the system only learns about what it already shows).

Applications

  • E-commerce: Product recommendations based on browsing and purchase history (Amazon, Flipkart).
  • Video/Music streaming: Netflix uses deep learning to recommend shows based on watch history; Spotify uses it for playlist generation.
  • Social media: Feed ranking and content recommendation on platforms like YouTube, Instagram — using user engagement history (likes, shares, watch time).
  • Advertising: Predicting click-through rates (CTR) for ads based on user behaviour history.
