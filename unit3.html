21. What are autoencoders, and how do they relate to principal component analysis (PCA) in terms of dimensionality reduction?

Autoencoder: a feedforward network trained to reconstruct its own input. Encoder: h = g(Wx+b). Decoder: x̂ = f(W*h+c). Trained by minimizing reconstruction loss, e.g. Σ(x̂ᵢ−xᵢ)ᵀ(x̂ᵢ−xᵢ).

  • Undercomplete (dim(h) < dim(x)): if x can still be reconstructed perfectly, h is a loss-free, compressed encoding capturing the important characteristics of x — directly analogous to PCA's goal.
  • Overcomplete (dim(h) ≥ dim(x)): risk of learning a trivial identity mapping unless regularized (see Q23, sparse/denoising/contractive AEs).

Formal equivalence to PCA

If the autoencoder uses a linear encoder, linear decoder, squared error loss, and the inputs are normalized (zero mean), then the optimal encoder weight matrix W is provably identical to the PCA projection matrix P (both equal the top-k eigenvectors of XᵀX). This is proven via SVD: the optimal solution to min‖X−HW*‖²_F is HW* = U.,≤kΣ_(k,k)V.,≤kᵀ, and matching terms shows H = XV.,≤k, i.e., W = V.,≤k — exactly the PCA basis.

Key difference: a non-linear autoencoder (sigmoid/tanh activations) can learn more powerful, non-linear manifolds that PCA (strictly linear) cannot capture — e.g. denoising autoencoders learn edge-detector-like filters that PCA simply cannot produce.

22. How do sparse autoencoders differ from traditional autoencoders, and what are some applications of sparse autoencoders in deep learning?

Motivation: an overcomplete autoencoder (hidden dimension \(\geq\) input dimension) has enough capacity to simply copy its input straight through to the output — learning the trivial identity function rather than anything meaningful about the data. A sparse autoencoder is one way to prevent this from happening.

How sparsity is enforced

For a hidden neuron with sigmoid activation, "active" means its output is near 1, and "inactive" means near 0. A sparse autoencoder adds a constraint forcing most hidden neurons to stay inactive for most inputs — only a small subset of neurons may fire for any given input.

The average activation of hidden neuron \(l\) across the dataset is:

\[ \hat{\rho}_l = \frac{1}{m}\sum_{i} h(x_i)_l \]

A small sparsity target \(\rho\) is chosen (e.g. \(\rho = 0.005\)), and a penalty is added that pushes \(\hat{\rho}_l\) toward \(\rho\) for every hidden neuron \(l\):

\[ \Omega(\theta) = \sum_l \left[ \rho\log\frac{\rho}{\hat{\rho}_l} + (1-\rho)\log\frac{1-\rho}{1-\hat{\rho}_l} \right] \]

This is a KL-divergence-style term between two Bernoulli distributions (one with mean \(\rho\), one with mean \(\hat{\rho}_l\)) — it is minimized exactly when \(\hat{\rho}_l = \rho\), i.e. when the neuron's actual average activation matches the sparsity target. The total loss being minimized is:

\[ \hat{L}(\theta) = L(\theta) + \Omega(\theta) \]

where \(L(\theta)\) is the ordinary reconstruction loss. The network is now optimizing two competing objectives at once: reconstruct the input well (\(L\)), while keeping most neurons inactive (\(\Omega\)) — this tension is exactly what prevents the trivial identity solution.

How it differs from a traditional (vanilla) autoencoder

Traditional AESparse AE
No constraint on how many hidden neurons are allowed to fireExplicit penalty \(\Omega(\theta)\) forcing most neurons to stay near-inactive
An overcomplete AE can trivially copy the input through to the outputSparsity prevents this — the network must reconstruct using only a few active neurons, forcing it to learn genuinely useful, disentangled features
Learned filters, when visualized, often look unstructured or noisyLearned filters tend to be more interpretable — e.g. localized, pen-stroke-like or edge-like detectors

Applications

  • Unsupervised feature/representation learning, used as a pretraining step before a supervised classifier.
  • Anomaly detection — sparse codes learned on normal data tend to reconstruct anomalous inputs poorly, which can be used as an anomaly signal.
  • Interpretable feature extraction, since each active neuron tends to correspond to a specific, localized pattern rather than an entangled mixture of features.
  • Compression — sparse codes are efficient representations, since most units are inactive for any given input.

23. How does bias-variance trade-off can be managed using regularization techniques such as L2 regularization?

  • Bias-variance tradeoff: high-bias models (too simple) underfit; high-variance models (too complex, too many free parameters relative to data) overfit — memorize training data, generalize poorly.
  • L2 regularization (weight decay): add a penalty term λ‖θ‖² to the loss function: L̂(θ) = L(θ) + λ‖θ‖². Discourages weights from growing large, which keeps the function smoother/simpler.
  • Effect on gradient: adds a simple λW term to ∂L/∂W — easy to implement, effectively "shrinks" weights toward zero at every update.
  • By constraining model complexity (effectively reducing the hypothesis space), L2 reduces variance at the cost of slightly increased bias — moving the model toward the sweet spot of the tradeoff curve rather than overfitting.
  • Larger λ → stronger regularization → lower variance / higher bias; smaller λ → closer to unregularized (higher variance, lower bias). λ is tuned via validation performance.
  • Related techniques achieving the same goal: early stopping, dataset augmentation, dropout, parameter sharing/tying — all reduce effective model capacity or effective training-data variance to control overfitting.
General regularization theory + weight-decay formulation as used for autoencoders in CS7015 Lecture 7, Module 7.3.

24. What is the role of denoising autoencoders in deep learning, and how do they enhance the robustness of a model?

Core idea: a denoising autoencoder (DAE) deliberately corrupts its input using a stochastic process \(P(\tilde{x}_{ij}\mid x_{ij})\) before feeding it into the encoder — but the training objective still asks the network to reconstruct the original, uncorrupted input, not the corrupted one it actually received.

Corruption process

\[ P(\tilde{x}_{ij}=0 \mid x_{ij}) = q \qquad \text{(flipped to 0 with probability } q\text{)} \] \[ P(\tilde{x}_{ij}=x_{ij} \mid x_{ij}) = 1-q \qquad \text{(retained as-is otherwise)} \]

(An alternative corruption process is additive Gaussian noise: \(\tilde{x}_{ij} = x_{ij} + \mathcal{N}(0,1)\).)

Why this works — the key mechanism

The training objective is:

\[ \min \sum_{i,j} (\hat{x}_{ij} - x_{ij})^2 \]

Notice this compares the reconstruction \(\hat{x}\) against the original \(x\), not the corrupted \(\tilde{x}\) that was actually fed in. This one design choice is what makes denoising autoencoders work: it is no longer useful for the model to simply copy the corrupted input \(\tilde{x}_i\) through to \(h\) and back out to \(\hat{x}_i\), because that copy would reproduce the corrupted version — and the loss explicitly penalizes that mismatch. The only way to reduce the loss is for the model to infer the missing/corrupted values from their correlations with the other, uncorrupted elements of \(x_i\). In other words, it is forced to learn the true underlying structure of the data, rather than memorizing an identity mapping.

Evidence of robustness (from visualization)

  • A vanilla (non-denoising) autoencoder's hidden neurons, when visualized as the input pattern that maximally activates each one, do not learn many meaningful patterns.
  • A denoising autoencoder's hidden neurons behave like pen-stroke detectors — for example, a neuron may fire specifically for a stroke shape found in digits like '0', '2', '3', '8', '9'.
  • As the corruption level \(q\) increases (e.g. from 25% to 50%), the learned filters become wider — the neuron must draw on more surrounding pixels to remain confident about a stroke, since any single pixel's information is now less reliable.
  • On other datasets, DAE hidden neurons behave like edge detectors — a capability plain PCA cannot produce, since PCA is restricted to linear, global directions of variance.

Role in deep learning

  • Learns more robust, generalizable representations than a vanilla autoencoder, since the network cannot rely on trivially copying its input.
  • Useful as an unsupervised pretraining step — for example, on MNIST digit recognition, a DAE can first learn a compact representation \(h \in \mathbb{R}^d\), and a classifier is then trained on \(h\) instead of on the raw 784-dimensional pixel input.
  • Improves resilience to noisy or corrupted real-world inputs at inference time, since the model was explicitly trained to "see through" corruption during training.

25. Explain the concept of contractive autoencoders and how they differ from traditional autoencoders.

A contractive autoencoder (CAE) also prevents an overcomplete autoencoder from learning the trivial identity function — but does so differently from sparse or denoising AEs: by penalizing the sensitivity of the hidden representation to small input changes.

Regularization term

Ω(θ) = ‖J_x(h)‖²_F = Σⱼ Σₗ (∂hₗ/∂xⱼ)²

where J_x(h) is the Jacobian of the encoder — the (l,j) entry captures how much hidden neuron l's output changes for a small change in input dimension j.

Intuition

  • If ∂h₁/∂x₁ = 0, neuron 1 is completely insensitive to variations in x₁ — but this conflicts with the reconstruction objective L(θ), which needs h to capture variations in x in order to reconstruct it well.
  • This is deliberate: pitting L(θ) (capture important variations) against Ω(θ) (don't capture variations) creates a tradeoff — the network ends up sensitive only to the important variations observed in training data, and insensitive to unimportant/noisy directions.
  • Geometric picture: for data varying mainly along direction u1 (important, high signal) and only slightly along u2 (noise), a CAE learns to be sensitive to u1 while suppressing sensitivity to u2 — balancing good reconstruction against low sensitivity.

Difference from traditional / sparse / denoising AEs

TypeMechanism to prevent identity mapping
Traditional (vanilla) AENone — can trivially learn identity if overcomplete
Sparse AEPenalizes average activation of hidden neurons (KL term)
Denoising AECorrupts input; forces reconstruction of the clean original
Contractive AEPenalizes the Jacobian (sensitivity) of hidden layer w.r.t. input directly
