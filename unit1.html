1. Define Deep Learning. Explain its uses and applications.

Deep Learning (DL) is the branch of machine learning that uses neural networks with many layers to learn a function \(\hat{y}=f(x)\) directly from data. Each layer transforms the output of the layer below, so the network discovers useful features itself instead of relying on hand-crafted ones.

\[\hat{y} = f(x) = O(a_L), \qquad a_i = b_i + W_i\,h_{i-1}, \qquad h_i = g(a_i)\quad (h_0 = x)\]

The parameters \(\theta=\{W_i, b_i\}\) are learned by minimising a loss over the \(N\) training examples, using backpropagation to get gradients and gradient descent to update:

\[ \operatorname*{arg\,min}_{\theta}\ \mathcal{L}(\theta)=\frac{1}{N}\sum_{i=1}^{N}\ell\big(f(x_i;\theta),\,y_i\big), \qquad \theta_{t+1}=\theta_t-\eta\,\nabla_\theta\mathcal{L}(\theta_t) \]

Deep learning vs classical machine learning

Why it works now

  • Data: large labelled datasets (e.g. ImageNet).
  • Compute: GPUs make training deep networks practical.
  • Algorithms: better activations (ReLU), initialisation, Batch Normalisation, dropout and optimisers (Adam).

Layers as a feature hierarchy (image example)

LayerWhat it computesExample for a digit image

This is why depth matters: each layer re-uses the features of the layer below, so complex concepts are built from simple ones. A shallow model would have to learn the whole mapping from pixels to class in one step.

One training iteration

  1. Forward pass: compute \(a_i,h_i\) layer by layer to get \(\hat y\).
  2. Loss: compare with the true label, e.g. cross-entropy \(\ell=-\log\hat y_{\ell}\) for the true class.
  3. Backward pass: backpropagation gives \(\nabla_{W_i}\mathcal L\) for every layer (Q6).
  4. Update: \(W_i\leftarrow W_i-\eta\nabla_{W_i}\mathcal L\); repeat for many epochs.

2. What is a perceptron, and how does the perceptron learning algorithm work? Explain with an example.

The perceptron was proposed by Frank Rosenblatt (1958) as a more general computational model than the McCulloch–Pitts neuron. Unlike the MP neuron, a perceptron assigns numerical weights to each input, and these weights can be learned from data rather than hand-coded. Inputs are also no longer restricted to boolean values — real-valued inputs are allowed.

Perceptron rule

y = 1 if Σ(i=0 to n) wᵢ·xᵢ ≥ 0, else y = 0
where x₀ = 1 and w₀ = −θ (the bias)

A perceptron separates the input space into two halves using a hyperplane wᵀx = 0. It can only implement linearly separable functions.

Perceptron Learning Algorithm

P ← inputs with label 1
N ← inputs with label 0
Initialize w randomly
while not converged:
    pick random x ∈ P ∪ N
    if x ∈ P and w·x < 0:
        w = w + x
    if x ∈ N and w·x ≥ 0:
        w = w − x

Intuition: if a positive point is misclassified (angle between w and x is > 90°), we nudge w toward x (w = w + x) to reduce that angle. If a negative point is misclassified (angle < 90°), we push w away from x (w = w − x). This is provably convergent in finite steps if the data is linearly separable (proof via cos β growing while bounded by 1).

Worked example — Perceptron Learning Algorithm for OR gate

If the training data is linearly separable, the perceptron learning algorithm is guaranteed to converge to a set of weights that correctly classifies all training examples in a finite number of steps. The OR function is linearly separable, so the perceptron can learn it.

3. Discuss single layer perceptrons in detail.

A single layer perceptron (SLP) has an input layer connected directly to one output perceptron — there is no hidden layer. Inputs are real-valued, the weights and the threshold are learnable. Writing the bias as \(x_0=1\) and \(w_0=-\theta\):

\[y=\begin{cases}1 & \text{if } \sum_{i=0}^{n} w_i x_i \ge 0\\[2pt] 0 & \text{if } \sum_{i=0}^{n} w_i x_i < 0\end{cases}\qquad\text{i.e.}\quad y=1 \iff \mathbf{w}^{T}\mathbf{x}\ge 0\]

Geometric interpretation

The equation \(\sum_{i=1}^{n} w_i x_i-\theta=0\) is a line (2-D) or hyperplane (n-D) that splits the input space in two. \(\mathbf{w}\) is the normal to this hyperplane; inputs on its positive side give \(y=1\), the rest give \(y=0\). So an SLP can only implement linearly separable functions.

What it can represent

FunctionWeights (\(w_0, w_1, w_2\))Condition
AND\(-2,\ 1,\ 1\)\(x_1+x_2\ge 2\)
OR\(-1,\ 1,\ 1\)\(x_1+x_2\ge 1\)
NOT (one input)\(0,\ -1\)\(-x_1\ge 0\)

Learning — perceptron learning algorithm

Let \(P\) = inputs with label 1, \(N\) = inputs with label 0, initialise \(\mathbf{w}\) randomly and repeat until every point is classified correctly:

pick a random x in P ∪ N
if x ∈ P and w·x < 0 :  w = w + x
if x ∈ N and w·x ≥ 0 :  w = w − x

Convergence theorem: if \(P\) and \(N\) are finite and linearly separable, the algorithm makes only a finite number of updates.

Limitation — XOR

For XOR we need \(w_0<0\), \(w_1\ge -w_0\), \(w_2\ge -w_0\) and \(w_1+w_2<-w_0\). Adding the 2nd and 3rd gives \(w_1+w_2\ge -2w_0 > -w_0\) (as \(w_0<0\)), which contradicts the 4th. So no weights exist. Of the \(2^{2^2}=16\) boolean functions of two inputs, only XOR and XNOR are not linearly separable. This limitation (Minsky & Papert, 1969) is what motivates multilayer networks (Q4).

Worked example — learning OR with the perceptron rule

Inputs are written with the bias input first, \(x=(x_0,x_1,x_2)=(1,x_1,x_2)\). Start with \(w=(0,0,0)\). Rule: if \(x\in P\) and \(w\cdot x<0\), then \(w\leftarrow w+x\); if \(x\in N\) and \(w\cdot x\ge0\), then \(w\leftarrow w-x\).

StepPoint \(x\) (label)\(w\cdot x\)ActionNew \(w\)
1(1,0,0) — N0wrong (≥0): subtract(−1, 0, 0)
2(1,0,1) — P−1wrong: add(0, 0, 1)
3(1,0,0) — N0wrong: subtract(−1, 0, 1)
4(1,1,0) — P−1wrong: add(0, 1, 1)

Final \(w=(-1,1,1)\): the four points give \(w\cdot x=-1,0,0,1\), i.e. outputs 0, 1, 1, 1 — all correct, and it is exactly the OR weights from the table above. Every update moved the line towards the misclassified point; this is how the convergence theorem works.

4. What are multilayer perceptrons (MLPs), and how do they differ from single-layer perceptrons?

A multilayer perceptron (MLP) is a feedforward network of perceptrons with an input layer, one or more hidden layers and an output layer. Every unit in a layer feeds the units of the next layer; there are no connections inside a layer or backwards.

Why a hidden layer helps — XOR with 4 hidden perceptrons

Use one hidden perceptron per input pattern. Unit \(h_k\) has weight \(+1\) on an input that is 1 in its pattern, \(-1\) on an input that is 0, and bias \(-(\text{number of 1s in the pattern})\), so it fires only for its own pattern. The output perceptron then just selects which patterns should give 1.

\[y=1\ \text{ if }\ \sum_{i=1}^{4} w_i h_i \ge w_0\]
InputXORCondition on output weights
(0,0)0\(w_1 < w_0\)
(0,1)1\(w_2 \ge w_0\)
(1,0)1\(w_3 \ge w_0\)
(1,1)0\(w_4 < w_0\)

These four conditions are consistent (e.g. \(w_0=1,\ w_1=w_4=0,\ w_2=w_3=1\)), so XOR is representable — unlike a single perceptron.

Representation power

  • Any boolean function of \(n\) inputs can be represented exactly by one hidden layer of \(2^n\) perceptrons plus one output perceptron (sufficient, not necessary — AND needs just one). The catch: the width grows exponentially with \(n\).
  • With sigmoid neurons, one hidden layer can approximate any continuous function to any desired precision (universal approximation: Cybenko 1989, Hornik 1991).

5. Explain the role of sigmoid neurons in feed forward neural networks.

Why the perceptron is not enough

A perceptron's output is a step function: a tiny change in \(w\) or \(b\) can suddenly flip the output from 0 to 1. It is not smooth, not continuous at the threshold and not differentiable, so gradients are useless and gradient descent cannot train a deep network built from it.

Sigmoid neuron

\[y=f(x)=\sigma(w^{T}x+b)=\frac{1}{1+e^{-(w^{T}x+b)}},\qquad 0<f(x)<1\]

It is smooth, continuous and differentiable, and its output can be read as a probability. Its derivative has a very convenient form:

\[\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^{2}}=\sigma(z)\bigl(1-\sigma(z)\bigr)\]

Role in a feedforward network

  1. Non-linearity in hidden layers: \(h_i=g(a_i)=\sigma(a_i)\). Without a non-linear \(g\), stacked layers collapse to a single linear map.
  2. Differentiability makes learning possible: backpropagation needs \(g'(a_i)\), here \(g'(a_i)=h_i\odot(1-h_i)\), in \(\nabla_{a_i}L=\nabla_{h_i}L\odot g'(a_i)\).
  3. Probabilistic output: for binary classification the output \(\hat y=\sigma(a_L)\in(0,1)\) is the probability of class 1.
  4. Representation power: a network with one hidden layer of sigmoid neurons can approximate any continuous function to any desired precision (Cybenko 1989, Hornik 1991).

Learning a single sigmoid neuron

With squared error \(L(w,b)=\tfrac12\sum_{i=1}^{N}\bigl(f(x_i)-y_i\bigr)^2\), the chain rule gives

\[\nabla w=\sum_{i=1}^{N}\bigl(f(x_i)-y_i\bigr)\,f(x_i)\bigl(1-f(x_i)\bigr)\,x_i,\qquad \nabla b=\sum_{i=1}^{N}\bigl(f(x_i)-y_i\bigr)\,f(x_i)\bigl(1-f(x_i)\bigr)\]
\[w_{t+1}=w_t-\eta\,\nabla w_t,\qquad b_{t+1}=b_t-\eta\,\nabla b_t\]

Drawbacks (lead to Unit IV)

  • Saturation: for large \(|z|\), \(\sigma'(z)\to 0\) and the maximum is only 0.25, so gradients shrink layer after layer (vanishing gradients).
  • Output is not zero-centred, and \(e^{-z}\) is expensive — hence tanh and ReLU.

Numbers: why saturation hurts

Backpropagation multiplies one factor \(g'(a_i)\le0.25\) per layer. Even in the best case, through 10 sigmoid layers the gradient is scaled by \(0.25^{10}\approx10^{-6}\), so early layers barely learn. A neuron with \(|z|\) around 5 passes almost no gradient at all. This is the vanishing-gradient problem, and the reason ReLU-type units replaced sigmoid in hidden layers (Q32).

6. What is back propagation, and how is it used to train feed forward neural networks?

Backpropagation is the algorithm used to compute the gradient of the loss function \(L(\theta)\) with respect to every weight and bias in a feedforward network, so that gradient descent can update the parameters.

Where backpropagation fits in training

Gradient descent needs \(\nabla_\theta L(\theta)\) for every weight and bias. Backpropagation computes all of them in one backward sweep that reuses the values stored during the forward pass, instead of differentiating each weight separately.

\[\theta_{t+1}=\theta_t-\eta\,\nabla_\theta L(\theta_t),\qquad \theta=[W_1,\dots,W_L,\,b_1,\dots,b_L]\]

Notation

SymbolMeaning
\(W_i,\ b_i\)weight matrix and bias of layer \(i\)
\(a_i\)pre-activation: \(a_i = b_i + W_i h_{i-1}\)
\(h_i\)activation: \(h_i = g(a_i)\)
\(\hat{y}\)predicted output

The core idea — responsibility via the chain rule

\[\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_3} \cdot \frac{\partial a_3}{\partial h_2} \cdot \frac{\partial h_2}{\partial a_2} \cdot \frac{\partial a_2}{\partial h_1} \cdot \frac{\partial h_1}{\partial a_1} \cdot \frac{\partial a_1}{\partial W_1}\]

Backpropagation computes gradients layer by layer, from output backward, reusing each layer's result for the layer before it.

Three gradient computations, in order

  1. Output pre-activation: \(\frac{\partial L}{\partial a_L} = \hat{y} - e^{(\ell)}\) (softmax + cross-entropy)
  2. Hidden layers (backward): \(\frac{\partial L}{\partial h_i} = W_{i+1}^{\top} \cdot \frac{\partial L}{\partial a_{i+1}}\), then \(\frac{\partial L}{\partial a_i} = \frac{\partial L}{\partial h_i} \odot g'(a_i)\)
  3. Parameters: \(\frac{\partial L}{\partial W_k} = \frac{\partial L}{\partial a_k} \cdot h_{k-1}^{\top}\), \(\frac{\partial L}{\partial b_k} = \frac{\partial L}{\partial a_k}\)

Forward propagation

for k = 1 to L-1:
    a_k = b_k + W_k h_(k-1)
    h_k = g(a_k)
a_L = b_L + W_L h_(L-1)
y_hat = O(a_L)

Complete training loop

initialise θ_0
while t < max_iterations:
    h_1..h_(L-1), a_1..a_L, y_hat = forward_propagation(θ_t)
    ∇θ_t = backward_propagation(h, a, y, y_hat)
    θ_(t+1) = θ_t - η ∇θ_t
    t = t + 1

Backward propagation

backward_propagation:
    dL/daL = y_hat - e(ℓ)
    for k = L down to 1:
        dL/dWk = (dL/dak) · h_(k-1)ᵀ
        dL/dbk = dL/dak
        dL/dh_(k-1) = Wkᵀ · (dL/dak)
        dL/da_(k-1) = dL/dh_(k-1) ⊙ g'(a_(k-1))

Activation derivatives needed for \(g'(a)\)

\(g(z)\)\(g'(z)\)
Logistic \(\sigma(z)\)\(g(z)\bigl(1-g(z)\bigr)\)
tanh\(1-g(z)^2\)

For a real-valued target with linear output and squared error \(L=\tfrac12\sum_j(\hat y_j-y_j)^2\), the output gradient is \(\nabla_{a_L}L=\hat y-y\), the same form as for softmax with cross-entropy.

9. Write the differences between Feed Forward and Feed Backward Neural networks.

Note: "feed backward" here means feedback (recurrent) networks. Backpropagation is a training procedure that runs on a feedforward network; it is not a separate network type.

Feedforward network: neurons are connected in layers with no cycles; the output depends only on the current input.

\[h_i=g(W_i\,h_{i-1}+b_i),\qquad \hat y=O(W_L h_{L-1}+b_L)\]

Feedback / recurrent network: the output of a unit is fed back, so the state carries information from earlier time steps.

\[s_t=\sigma(U x_t+W s_{t-1}+b),\qquad y_t=O(V s_t+c)\]
Feedforward networkFeedback / recurrent network
ConnectionsAcyclic: layer \(i\) → layer \(i+1\)Contain loops; state fed back to itself
MemoryNone — each input handled independentlyHidden state \(s_t\) remembers the past
InputFixed-size vectorSequences of variable length
ParametersSeparate \(W_i\) per layerSame \(U,W,V\) shared across all time steps
TrainingBackpropagationBackpropagation Through Time (BPTT)
Main difficultyVanishing gradients in deep stacksVanishing / exploding gradients over time
ExamplesMLP, CNNRNN, LSTM, GRU
ApplicationsImage classification, tabular dataLanguage modelling, speech, time series

Why the recurrent network has memory (unrolling)

Unrolling the recurrence over three steps (with \(s_0=0\)) shows that the output depends on all earlier inputs:

\[s_3=\sigma\Bigl(Ux_3+W\,\sigma\bigl(Ux_2+W\,\sigma(Ux_1)\bigr)\Bigr)\]

In a feedforward network \(\hat y\) depends only on the present \(x\); here \(s_3\) is a function of \(x_1,x_2,x_3\), with the same \(U,W\) reused at every step. That sharing is why the number of parameters does not grow with the sequence length.

Which one to use

  • Feedforward: the inputs are independent, fixed-size (an image, a row of features) and the order does not matter.
  • Feedback / recurrent: the data is a sequence and the meaning of the current element depends on the earlier ones (a sentence, a speech signal, sensor readings over time).
Source: CS7015 Lectures 3–4 (feedforward), Lecture 14 (RNN, BPTT) — Khapra.

10. Write a python code for backward propagation in a neural network.

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    return a * (1 - a)

np.random.seed(0)
input_size, hidden_size, output_size = 2, 2, 1
lr = 0.5

W1 = np.random.randn(input_size, hidden_size)
b1 = np.zeros((1, hidden_size))
W2 = np.random.randn(hidden_size, output_size)
b2 = np.zeros((1, output_size))

X = np.array([[1, 1]])
y = np.array([[0]])

# forward pass
a1 = X.dot(W1) + b1
h1 = sigmoid(a1)
a2 = h1.dot(W2) + b2
y_hat = sigmoid(a2)

# error
error = y - y_hat
loss = np.mean(0.5 * error ** 2)

# backward pass
delta_output = -error * sigmoid_derivative(y_hat)
grad_W2 = h1.T.dot(delta_output)
grad_b2 = np.sum(delta_output, axis=0, keepdims=True)

delta_hidden = delta_output.dot(W2.T) * sigmoid_derivative(h1)
grad_W1 = X.T.dot(delta_hidden)
grad_b1 = np.sum(delta_hidden, axis=0, keepdims=True)

# update
W2 -= lr * grad_W2
b2 -= lr * grad_b2
W1 -= lr * grad_W1
b1 -= lr * grad_b1

print("Loss:", loss)
print("Updated W1:\n", W1)
print("Updated W2:\n", W2)
Structure matches CS7015 Lecture 4 (Khapra), Module 4.8.
