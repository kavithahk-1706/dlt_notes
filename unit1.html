1. Define Deep Learning. Explain its uses and applications.

Definition: Deep Learning is a subfield of machine learning based on artificial neural networks with multiple layers (hence "deep") that automatically learn hierarchical representations of data — simple features in early layers, complex/abstract features in later layers — without hand-engineered feature extraction.

Key points to expand in the exam

  • Inspired loosely by biological neurons; built from layers of artificial neurons (weights, biases, activations).
  • Learns representations directly from raw data (pixels, audio waveforms, text) via backpropagation + gradient descent.
  • Contrast with classical ML: classical ML needs manual feature engineering; DL learns features automatically through hierarchy of layers.

Applications (give 1–2 lines each)

  • Computer Vision: image classification, object detection, face recognition (CNNs).
  • NLP: machine translation, sentiment analysis, chatbots, LLMs (RNNs/Transformers).
  • Speech: speech recognition, voice assistants.
  • Recommendation systems: Netflix, YouTube, e-commerce personalization.
  • Healthcare: medical image diagnosis, drug discovery.
  • Autonomous vehicles: perception, path planning.

2. What is a perceptron, and how does the perceptron learning algorithm work? Explain with an example.

The perceptron was proposed by Frank Rosenblatt (1958) as a more general computational model than the McCulloch–Pitts neuron. Unlike the MP neuron, a perceptron assigns numerical weights to each input, and these weights can be learned from data rather than hand-coded. Inputs are also no longer restricted to boolean values — real-valued inputs are allowed.

Perceptron rule

y = 1 if Σ(i=0 to n) wᵢ·xᵢ ≥ 0, else y = 0
where x₀ = 1 and w₀ = −θ (the bias)

A perceptron separates the input space into two halves using a hyperplane wᵀx = 0. It can only implement linearly separable functions.

Perceptron Learning Algorithm

P ← inputs with label 1
N ← inputs with label 0
Initialize w randomly
while not converged:
    pick random x ∈ P ∪ N
    if x ∈ P and w·x < 0:
        w = w + x
    if x ∈ N and w·x ≥ 0:
        w = w − x

Intuition: if a positive point is misclassified (angle between w and x is > 90°), we nudge w toward x (w = w + x) to reduce that angle. If a negative point is misclassified (angle < 90°), we push w away from x (w = w − x). This is provably convergent in finite steps if the data is linearly separable (proof via cos β growing while bounded by 1).

Worked example — Perceptron Learning Algorithm for OR gate

If the training data is linearly separable, the perceptron learning algorithm is guaranteed to converge to a set of weights that correctly classifies all training examples in a finite number of steps. The OR function is linearly separable, so the perceptron can learn it.

3. Discuss single layer perceptrons in detail.

  • A single layer perceptron (SLP) has only an input layer directly connected to a single output neuron — no hidden layers.
  • Computes y = 1 if wᵀx ≥ 0 else 0. Geometrically draws one hyperplane through input space.
  • Can represent only linearly separable boolean functions (e.g. AND, OR, NOT) — cannot represent XOR.
  • Weights learned via the perceptron learning algorithm (see Q2); guaranteed to converge only if data is linearly separable (Perceptron Convergence Theorem).
  • Limitation exposed by Minsky & Papert (1969) — led to the "AI winter" until MLPs revived interest.

4. What are multilayer perceptrons (MLPs), and how do they differ from single-layer perceptrons?

  • MLP: a network with an input layer, one or more hidden layers, and an output layer.
  • Each hidden neuron fires for specific input regions; combining several such neurons lets the network carve up input space into more than one hyperplane region.
  • Key theorem (Khapra Lec 2): any boolean function of n inputs can be represented exactly by an MLP with one hidden layer containing 2ⁿ perceptrons + one output perceptron.
  • Differences table:
Single-layer PerceptronMLP
No hidden layer≥1 hidden layer
Only linearly separable functionsAny boolean/continuous function (given enough hidden units)
Simple perceptron rule updateTrained via backpropagation + gradient descent

5. Explain the role of sigmoid neurons in feed forward neural networks.

  • Perceptron's hard threshold is "harsh" — a tiny change in input flips the output completely.
  • Sigmoid neuron replaces this with a smooth function: y = σ(wx+b) = 1/(1+e⁻⁽ʷˣ⁺ᵇ⁾). Output is a continuous value between 0 and 1.
  • This smoothness is exactly what makes the loss function differentiable — enabling gradient descent to work.
  • Without smooth activations, we couldn't compute meaningful gradients for learning.

6. What is back propagation, and how is it used to train feed forward neural networks?

Backpropagation is the algorithm used to compute the gradient of the loss function \(L(\theta)\) with respect to every weight and bias in a feedforward network, so that gradient descent can update the parameters.

Notation

SymbolMeaning
\(W_i,\ b_i\)weight matrix and bias of layer \(i\)
\(a_i\)pre-activation: \(a_i = b_i + W_i h_{i-1}\)
\(h_i\)activation: \(h_i = g(a_i)\)
\(\hat{y}\)predicted output

The core idea — responsibility via the chain rule

\[\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_3} \cdot \frac{\partial a_3}{\partial h_2} \cdot \frac{\partial h_2}{\partial a_2} \cdot \frac{\partial a_2}{\partial h_1} \cdot \frac{\partial h_1}{\partial a_1} \cdot \frac{\partial a_1}{\partial W_1}\]

Backpropagation computes gradients layer by layer, from output backward, reusing each layer's result for the layer before it.

Three gradient computations, in order

  1. Output pre-activation: \(\frac{\partial L}{\partial a_L} = \hat{y} - e^{(\ell)}\) (softmax + cross-entropy)
  2. Hidden layers (backward): \(\frac{\partial L}{\partial h_i} = W_{i+1}^{\top} \cdot \frac{\partial L}{\partial a_{i+1}}\), then \(\frac{\partial L}{\partial a_i} = \frac{\partial L}{\partial h_i} \odot g'(a_i)\)
  3. Parameters: \(\frac{\partial L}{\partial W_k} = \frac{\partial L}{\partial a_k} \cdot h_{k-1}^{\top}\), \(\frac{\partial L}{\partial b_k} = \frac{\partial L}{\partial a_k}\)

Algorithm

backward_propagation:
    dL/daL = y_hat - e(ℓ)
    for k = L down to 1:
        dL/dWk = (dL/dak) · h_(k-1)ᵀ
        dL/dbk = dL/dak
        dL/dh_(k-1) = Wkᵀ · (dL/dak)
        dL/da_(k-1) = dL/dh_(k-1) ⊙ g'(a_(k-1))

10. Write a python code for backward propagation in a neural network.

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    return a * (1 - a)

np.random.seed(0)
input_size, hidden_size, output_size = 2, 2, 1
lr = 0.5

W1 = np.random.randn(input_size, hidden_size)
b1 = np.zeros((1, hidden_size))
W2 = np.random.randn(hidden_size, output_size)
b2 = np.zeros((1, output_size))

X = np.array([[1, 1]])
y = np.array([[0]])

# forward pass
a1 = X.dot(W1) + b1
h1 = sigmoid(a1)
a2 = h1.dot(W2) + b2
y_hat = sigmoid(a2)

# error
error = y - y_hat
loss = np.mean(0.5 * error ** 2)

# backward pass
delta_output = -error * sigmoid_derivative(y_hat)
grad_W2 = h1.T.dot(delta_output)
grad_b2 = np.sum(delta_output, axis=0, keepdims=True)

delta_hidden = delta_output.dot(W2.T) * sigmoid_derivative(h1)
grad_W1 = X.T.dot(delta_hidden)
grad_b1 = np.sum(delta_hidden, axis=0, keepdims=True)

# update
W2 -= lr * grad_W2
b2 -= lr * grad_b2
W1 -= lr * grad_W1
b1 -= lr * grad_b1

print("Loss:", loss)
print("Updated W1:\n", W1)
print("Updated W2:\n", W2)
