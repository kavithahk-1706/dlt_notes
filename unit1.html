1. Define Deep Learning. Explain its uses and applications.

Definition: Deep Learning is a subfield of machine learning based on artificial neural networks with multiple layers (hence "deep") that automatically learn hierarchical representations of data — simple features in early layers, complex/abstract features in later layers — without hand-engineered feature extraction.

Key points to expand in the exam

  • Inspired loosely by biological neurons; built from layers of artificial neurons (weights, biases, activations).
  • Learns representations directly from raw data (pixels, audio waveforms, text) via backpropagation + gradient descent.
  • Contrast with classical ML: classical ML needs manual feature engineering; DL learns features automatically through hierarchy of layers.

Applications (give 1–2 lines each)

  • Computer Vision: image classification, object detection, face recognition (CNNs).
  • NLP: machine translation, sentiment analysis, chatbots, LLMs (RNNs/Transformers).
  • Speech: speech recognition, voice assistants.
  • Recommendation systems: Netflix, YouTube, e-commerce personalization.
  • Healthcare: medical image diagnosis, drug discovery.
  • Autonomous vehicles: perception, path planning.

2. What is a perceptron, and how does the perceptron learning algorithm work? Explain with an example.

The perceptron was proposed by Frank Rosenblatt (1958) as a more general computational model than the McCulloch–Pitts neuron. Unlike the MP neuron, a perceptron assigns numerical weights to each input, and these weights can be learned from data rather than hand-coded. Inputs are also no longer restricted to boolean values — real-valued inputs are allowed.

Perceptron rule

y = 1 if Σ(i=0 to n) wᵢ·xᵢ ≥ 0, else y = 0
where x₀ = 1 and w₀ = −θ (the bias)

A perceptron separates the input space into two halves using a hyperplane wᵀx = 0. It can only implement linearly separable functions.

Perceptron Learning Algorithm

P ← inputs with label 1
N ← inputs with label 0
Initialize w randomly
while not converged:
    pick random x ∈ P ∪ N
    if x ∈ P and w·x < 0:
        w = w + x
    if x ∈ N and w·x ≥ 0:
        w = w − x

Intuition: if a positive point is misclassified (angle between w and x is > 90°), we nudge w toward x (w = w + x) to reduce that angle. If a negative point is misclassified (angle < 90°), we push w away from x (w = w − x). This is provably convergent in finite steps if the data is linearly separable (proof via cos β growing while bounded by 1).

Worked example — Perceptron Learning Algorithm for OR gate

3. Discuss single layer perceptrons in detail.

  • A single layer perceptron (SLP) has only an input layer directly connected to a single output neuron — no hidden layers.
  • Computes y = 1 if wᵀx ≥ 0 else 0. Geometrically draws one hyperplane through input space.
  • Can represent only linearly separable boolean functions (e.g. AND, OR, NOT) — cannot represent XOR.
  • Weights learned via the perceptron learning algorithm (see Q2); guaranteed to converge only if data is linearly separable (Perceptron Convergence Theorem).
  • Limitation exposed by Minsky & Papert (1969) — led to the "AI winter" until MLPs revived interest.

4. What are multilayer perceptrons (MLPs), and how do they differ from single-layer perceptrons?

  • MLP: a network with an input layer, one or more hidden layers, and an output layer — "multilayered network of perceptrons."
  • Each hidden neuron fires for specific input regions; combining several such neurons in a hidden layer lets the network carve up input space into more than one hyperplane region.
  • Key theorem (Khapra Lec 2): any boolean function of n inputs can be represented exactly by an MLP with one hidden layer containing 2ⁿ perceptrons + one output perceptron. So MLPs can represent even non-linearly-separable functions like XOR (SLPs cannot).
  • Differences table:
Single-layer PerceptronMLP
No hidden layer≥1 hidden layer
Only linearly separable functionsAny boolean/continuous function (given enough hidden units)
Simple perceptron rule updateTrained via backpropagation + gradient descent

5. Explain the role of sigmoid neurons in feed forward neural networks.

  • Perceptron's hard threshold is "harsh" — a tiny change in input (e.g. rating 0.49 → 0.51) flips the output completely.
  • Sigmoid neuron replaces this with a smooth function: y = σ(wx+b) = 1/(1+e^−(wx+b)). Output is a continuous value between 0 and 1, not a hard 0/1.
  • This smoothness is exactly what makes the loss function differentiable — enabling gradient descent to work, since small changes in weights produce small, smooth changes in output/loss (no discontinuous jumps).
  • Without smooth activations, we couldn't compute meaningful gradients for learning — this directly motivates the shift from perceptrons to sigmoid-based feedforward networks trained by gradient descent + backpropagation.

6. What is back propagation, and how is it used to train feed forward neural networks?

Backpropagation is the algorithm used to compute the gradient of the loss function \(L(\theta)\) with respect to every weight and bias in a feedforward network, so that gradient descent can update the parameters. It is not a separate learning rule from gradient descent — it is the efficient method used to obtain the gradients that gradient descent then applies.

Notation used below

SymbolMeaning
\(x\)network input
\(W_i,\ b_i\)weight matrix and bias of layer \(i\)
\(a_i\)pre-activation of layer \(i\): \(a_i = b_i + W_i h_{i-1}\)
\(h_i\)activation of layer \(i\): \(h_i = g(a_i)\), where \(g\) is a non-linearity (e.g. sigmoid)
\(\hat{y}\)predicted output (from the final layer)
\(y\)true/target label
\(\theta\)the full set of trainable parameters \(\{W_1,b_1,\dots,W_L,b_L\}\)

Network diagram

The core idea — responsibility via the chain rule

A loss is observed only at the output. To know how much a weight deep inside the network (e.g. \(W_1\)) is "responsible" for that loss, we cannot connect it to the loss directly — we must pass responsibility back through every layer that lies between \(W_1\) and \(\hat{y}\). This is precisely what the chain rule computes:

\[ \frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a_3} \cdot \frac{\partial a_3}{\partial h_2} \cdot \frac{\partial h_2}{\partial a_2} \cdot \frac{\partial a_2}{\partial h_1} \cdot \frac{\partial h_1}{\partial a_1} \cdot \frac{\partial a_1}{\partial W_1} \]

Computed as one long product per weight, this is intractable for a deep network. Backpropagation avoids this by computing gradients layer by layer, from the output backward, reusing each layer's result for the layer before it — instead of re-deriving the full chain separately for every parameter.

Setup

For layer \(i\): pre-activation \(a_i = b_i + W_i h_{i-1}\), activation \(h_i = g(a_i)\). The output layer uses softmax, \(\hat{y}_j = \dfrac{e^{a_{L,j}}}{\sum_i e^{a_{L,i}}}\), paired with cross-entropy loss \(L(\theta) = -\log \hat{y}_\ell\), where \(\ell\) is the true class index.

Three gradient computations, in order

  1. Gradient w.r.t. the output pre-activation: \[ \nabla_{a_L} L(\theta) = -(e^{(\ell)} - \hat{y}) \] This has a clean closed form specifically because softmax is paired with cross-entropy loss — the two are designed to cancel neatly under differentiation, so no separate gradient-of-softmax step is needed.
  2. Gradient w.r.t. each hidden layer (computed backward, from layer \(L{-}1\) down to layer 1): \[ \nabla_{h_i} L(\theta) = (W_{i+1})^{\top}\big(\nabla_{a_{i+1}} L(\theta)\big) \] \[ \nabla_{a_i} L(\theta) = \nabla_{h_i} L(\theta) \odot g'(a_i) \] The first line pushes the gradient back through the weight matrix of the layer above; the second line pushes it through this layer's own activation function (elementwise product with the activation's derivative).
  3. Gradient w.r.t. the parameters themselves (this is the actual quantity gradient descent needs): \[ \nabla_{W_k} L(\theta) = \nabla_{a_k} L(\theta)\cdot h_{k-1}^{\top} \qquad \nabla_{b_k} L(\theta) = \nabla_{a_k} L(\theta) \]

Algorithm

for t in range(max_iterations):
    h, a, y_hat = forward_propagation(theta_t)
    grad_theta_t = backward_propagation(h, a, y, y_hat)
    theta_(t+1) = theta_t - eta * grad_theta_t

backward_propagation:
    grad_aL = -(e(y) - y_hat)
    for k = L down to 1:
        grad_Wk = grad_ak . h_(k-1)^T
        grad_bk = grad_ak
        grad_h_(k-1) = Wk^T . grad_ak
        grad_a_(k-1) = grad_h_(k-1) (elementwise*) g'(a_(k-1))

Why this matters for training

Without backpropagation, computing the gradient for every individual weight would require separately expanding a full chain-rule product per parameter — computationally infeasible for networks with millions of parameters. Backpropagation converts this into a single backward pass that computes and reuses each layer's gradient exactly once, which is what makes training deep networks computationally tractable.

Method (for reference — same structure as Q7, but with biases, and repeated for two tuples):

  1. Step 1 — Forward pass: \(I_j = \sum_i w_{ij}x_i + b_j\), \(O_j = \dfrac{1}{1+e^{-I_j}}\), for each hidden unit then the output unit. Then \(\text{Err} = y - O_{\text{output}}\).
  2. Step 2 — Backpropagation: \(\text{Err}_k = O_k(1-O_k)(y-O_k)\) at the output; \(\text{Err}_j = O_j(1-O_j)\sum_k \text{Err}_k\, w_{jk}\) at each hidden unit, working backward.
  3. Step 3 — Update weights and biases: \(w_{ij} = w_{ij} + \alpha\, \text{Err}_j\, O_i\); \(b_j = b_j + \alpha\, \text{Err}_j\).
  4. Repeat for tuple 2, using the updated weights/biases from tuple 1 as the new starting point.

10. Write a python code for backward propagation in a neural network using concepts like error calculation, and learning rate.

Simple, from-scratch backprop for a single-hidden-layer network with sigmoid activations — matches the derivation in Q6/Q8 exactly (error → delta → weight update).

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    # a is already sigmoid(z)
    return a * (1 - a)

# --- network setup ---
np.random.seed(0)
input_size, hidden_size, output_size = 2, 2, 1
lr = 0.5   # learning rate

W1 = np.random.randn(input_size, hidden_size)
b1 = np.zeros((1, hidden_size))
W2 = np.random.randn(hidden_size, output_size)
b2 = np.zeros((1, output_size))

X = np.array([[1, 1]])   # example input
y = np.array([[0]])      # target output

# --- forward pass ---
a1 = X.dot(W1) + b1
h1 = sigmoid(a1)
a2 = h1.dot(W2) + b2
y_hat = sigmoid(a2)

# --- error calculation ---
error = y - y_hat
loss = np.mean(0.5 * error ** 2)

# --- backward pass ---
delta_output = -error * sigmoid_derivative(y_hat)          # dL/da2
grad_W2 = h1.T.dot(delta_output)
grad_b2 = np.sum(delta_output, axis=0, keepdims=True)

delta_hidden = delta_output.dot(W2.T) * sigmoid_derivative(h1)  # dL/da1
grad_W1 = X.T.dot(delta_hidden)
grad_b1 = np.sum(delta_hidden, axis=0, keepdims=True)

# --- gradient descent update ---
W2 -= lr * grad_W2
b2 -= lr * grad_b2
W1 -= lr * grad_W1
b1 -= lr * grad_b1

print("Loss:", loss)
print("Updated W1:\n", W1)
print("Updated W2:\n", W2)

Mapping to theory (say this in the exam if asked to explain): delta_output = ∇aLL(θ) from Q6, delta_hidden = ∇aL(θ) for the hidden layer computed via (Wᵀ · downstream delta) ⊙ g′(a), and the weight gradients follow ∇W = δ · hᵀ exactly as derived.

Structure matches the backprop pseudocode in CS7015 Lecture 4 (Khapra), Module 4.8.
