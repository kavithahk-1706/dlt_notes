33. Explain the general architecture of a Convolutional Neural Network (CNN). Describe the function of each layer with a neat diagram.

A Convolutional Neural Network (CNN) is a specialised feedforward network designed to process data with a grid-like topology (e.g., images). It exploits spatial locality and parameter sharing to dramatically reduce the number of parameters compared to fully connected networks.

1. Convolution Layer

Applies a set of learnable filters (kernels) of size \(f \times f\) to the input. Each filter slides (convolves) across the spatial dimensions, computing dot products at every position to produce a feature map (activation map). For an input of size \(H \times W\) with filter size \(f\), stride \(s\), and padding \(p\):

\[\text{Output size} = \left\lfloor \frac{H - f + 2p}{s} \right\rfloor + 1\]

Parameter sharing: The same filter weights are applied at every spatial location, greatly reducing parameters. Each filter detects a specific feature (edge, texture, etc.) regardless of position.

2. Activation Layer (ReLU)

Applied element-wise after each convolution: \(\text{ReLU}(x) = \max(0, x)\). It introduces non-linearity, enabling the network to learn complex patterns. Negative values are zeroed out, promoting sparse representations.

3. Pooling Layer

Reduces the spatial dimensions of feature maps while retaining the most important information. Max pooling (most common) takes the maximum value in each \(k \times k\) window. Average pooling takes the mean. Pooling provides translation invariance and reduces computational cost for subsequent layers.

4. Fully Connected (FC) Layer

After several rounds of convolution and pooling, the feature maps are flattened into a 1D vector and passed to one or more FC layers. These layers learn global patterns by combining all the local features extracted by the convolutional layers. Each neuron in an FC layer is connected to every activation from the previous layer.

5. Output Layer

The final FC layer maps to the number of classes. A softmax activation converts the raw logits into a probability distribution over classes. The predicted class is \(\arg\max\) of this distribution. The loss is typically cross-entropy.

34. Explain the concept of Guided Backpropagation. Discuss its role in visualizing Convolutional Neural Networks.

Why Visualize CNNs?

CNNs are often treated as black boxes. Visualization techniques help us understand what features each layer has learned, and which parts of the input are responsible for a particular prediction. This is crucial for debugging, trust, and interpretability.

Background: Gradient-Based Visualization

The simplest approach is to compute the gradient of the output (or a specific class score) with respect to the input pixels: \(\frac{\partial S_c}{\partial \mathbf{x}}\). This tells us which pixels, if changed, would most affect the prediction. However, standard backpropagation through ReLU can produce noisy saliency maps.

How ReLU Backpropagation Works

Let \(h^l\) be the input to layer \(l\) and \(h^{l+1} = \text{ReLU}(h^l) = \max(0, h^l)\) be the output. Let \(G^{l+1} = \frac{\partial f}{\partial h^{l+1}}\) be the gradient received from the layer above.

In classical backpropagation:

\[G^{l} = \mathbb{1}[h^l > 0] \cdot G^{l+1}\]

Only positions where the forward-pass input was positive pass the gradient through (the ReLU gate).

In deconvolution (Zeiler & Fergus):

\[G^{l} = \mathbb{1}[G^{l+1} > 0] \cdot G^{l+1}\]

Only positive gradients (positive influence) are allowed to flow back, regardless of the forward-pass sign.

Guided Backpropagation

Guided Backpropagation (Springenberg et al., 2015) combines both conditions:

\[G^{l} = \mathbb{1}[h^l > 0] \cdot \mathbb{1}[G^{l+1} > 0] \cdot G^{l+1}\]

That is, the gradient flows back only when both the forward-pass activation was positive and the gradient flowing back is positive. This produces cleaner, sharper saliency maps compared to either method alone.

Role in CNN Visualization

Guided Backpropagation is used to generate saliency maps that highlight which pixels in the input image are most relevant to a particular neuron's activation or a class prediction. The resulting maps are high-resolution and show fine-grained details (edges, textures) that the network attends to. It can be applied to any intermediate layer or to the output class score.

Guided Grad-CAM

Guided Backpropagation can be combined with Grad-CAM (which produces coarse, class-discriminative heat maps) via element-wise multiplication to produce Guided Grad-CAM — visualisations that are both high-resolution and class-specific.

35. Explain the concept of Recurrent Neural Networks (RNNs). Discuss the role of Backpropagation Through Time (BPTT) in training RNNs.

Sequence Learning Problems

Many tasks involve sequential data where the current output depends not just on the current input but also on previous inputs — e.g., language modelling, speech recognition, POS tagging, machine translation. The input size is not fixed (sentences can have arbitrary length), and a feedforward network with fixed input size cannot handle this.

Recurrent Neural Networks

An RNN introduces a recurrent connection that maintains a hidden state \(\mathbf{s}_t\) across time steps. The same parameters are shared across all time steps (parameter sharing). At each time step \(t\):

\[\mathbf{s}_t = g(W \mathbf{s}_{t-1} + U \mathbf{x}_t + \mathbf{b})\] \[\mathbf{o}_t = V \mathbf{s}_t + \mathbf{c}\]

Here \(\mathbf{x}_t\) is the input at time \(t\), \(\mathbf{s}_t\) is the hidden state, \(\mathbf{o}_t\) is the output, \(W\) is the recurrent weight matrix (hidden-to-hidden), \(U\) is the input-to-hidden weight matrix, \(V\) is the hidden-to-output weight matrix, and \(g\) is an activation (typically tanh).

Backpropagation Through Time (BPTT)

To train an RNN, we unroll the network across all \(T\) time steps — treating it as a deep feedforward network with shared weights. The total loss is the sum of per-time-step losses:

\[\mathcal{L} = \sum_{t=1}^{T} \mathcal{L}_t\]

BPTT computes gradients by applying the chain rule backward through the unrolled graph. For the recurrent weights \(W\):

\[\frac{\partial \mathcal{L}}{\partial W} = \sum_{t=1}^{T} \frac{\partial \mathcal{L}_t}{\partial W} = \sum_{t=1}^{T} \sum_{k=1}^{t} \frac{\partial \mathcal{L}_t}{\partial \mathbf{s}_t} \left(\prod_{j=k+1}^{t} \frac{\partial \mathbf{s}_j}{\partial \mathbf{s}_{j-1}}\right) \frac{\partial \mathbf{s}_k}{\partial W}\]

Vanishing and Exploding Gradients

The product \(\prod_{j=k+1}^{t} \frac{\partial \mathbf{s}_j}{\partial \mathbf{s}_{j-1}}\) involves repeated multiplication of the Jacobian matrices. If the largest eigenvalue of \(W\) is < 1, the product shrinks exponentially — vanishing gradients — and the network cannot learn long-range dependencies. If > 1, it grows exponentially — exploding gradients.

Solutions: Gradient clipping (for exploding gradients), and architecturally: LSTMs and GRUs introduce gating mechanisms to maintain gradient flow over long sequences. Truncated BPTT limits the number of time steps the gradient is propagated back, trading long-range learning for computational feasibility.

36. Explore the GoogLeNet architecture and elucidate some of its significant contributions to the field of deep learning.

Overview

GoogLeNet (Szegedy et al., 2015) won the ILSVRC 2014 image classification challenge. It is a 22-layer deep network that introduced the Inception module as its core building block. Despite its depth, it has only ~4 million parameters (compared to AlexNet's ~60 million), making it both deeper and more parameter-efficient.

The Inception Module

Instead of choosing a single filter size for a convolutional layer, the Inception module applies multiple filter sizes in parallel and concatenates their outputs. A typical Inception module contains:

  • \(1 \times 1\) convolution — captures channel-wise patterns
  • \(3 \times 3\) convolution — captures local spatial patterns
  • \(5 \times 5\) convolution — captures wider spatial patterns
  • \(3 \times 3\) max pooling — retains dominant features

All branches operate on the same input and their outputs are concatenated along the channel dimension.

The Role of 1×1 Convolutions

\(1 \times 1\) convolutions serve as dimensionality reduction bottlenecks. Before the expensive \(3 \times 3\) and \(5 \times 5\) convolutions, a \(1 \times 1\) convolution reduces the number of input channels, dramatically reducing computation. This is the key to making the Inception module computationally feasible.

Global Average Pooling

Instead of multiple fully connected layers at the end (which dominate parameter counts in AlexNet/VGGNet), GoogLeNet uses global average pooling — each feature map is averaged into a single value. This replaces thousands of FC parameters and also acts as a structural regulariser. Accuracy improved by ~0.6% while significantly reducing parameters.

Auxiliary Classifiers

To combat the vanishing gradient problem in such a deep network, GoogLeNet attaches auxiliary classifiers at intermediate layers (connected to inception (4a) and inception (4d)). These inject gradients directly into intermediate layers during training, improving convergence. They are discarded at inference time.

Significant Contributions

  • Multi-scale feature extraction via parallel filters in a single layer
  • 1×1 convolutions for dimensionality reduction — now standard practice
  • Global average pooling replacing FC layers — reduces parameters by orders of magnitude
  • Auxiliary classifiers — a training strategy to help gradient flow in very deep networks
  • Showed that networks can go much deeper (22 layers) while using fewer parameters than shallower networks

37. Explain the Transformer architecture and Large Language Models (LLMs). Discuss their applications in deep learning.

Motivation: Limitations of RNNs

RNNs process sequences one token at a time, making them inherently sequential — they cannot be parallelised across time steps. They also struggle with long-range dependencies due to vanishing gradients, even with LSTMs/GRUs. The Transformer (Vaswani et al., 2017) addresses both issues by relying entirely on attention mechanisms instead of recurrence.

Self-Attention Mechanism

Self-attention allows each token in a sequence to attend to (look at) every other token directly, computing a weighted sum of representations. For each token, we compute three vectors from the input embedding \(\mathbf{x}\):

\[\mathbf{Q} = \mathbf{X} W_Q, \quad \mathbf{K} = \mathbf{X} W_K, \quad \mathbf{V} = \mathbf{X} W_V\]

\(\mathbf{Q}\) (Query), \(\mathbf{K}\) (Key), \(\mathbf{V}\) (Value) are obtained via learned linear projections. The attention output is:

\[\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}}\right) \mathbf{V}\]

The scaling factor \(\sqrt{d_k}\) prevents the dot products from becoming too large, which would push the softmax into saturation.

Multi-Head Attention

Instead of a single attention function, the Transformer uses multiple attention heads in parallel, each with different learned projections. This allows the model to attend to different types of relationships simultaneously:

\[\text{MultiHead}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) \, W_O\]

where each \(\text{head}_i = \text{Attention}(\mathbf{Q} W_Q^i, \mathbf{K} W_K^i, \mathbf{V} W_V^i)\).

Transformer Architecture

The original Transformer is an encoder-decoder model:

Encoder: A stack of \(N\) identical layers, each containing (i) a multi-head self-attention sublayer, and (ii) a position-wise feedforward sublayer. Each sublayer has a residual connection and layer normalisation.

Decoder: Similar to the encoder, but with an additional cross-attention sublayer that attends to the encoder's output. The self-attention in the decoder is masked to prevent attending to future positions (maintaining autoregressive generation).

Positional Encoding: Since there is no recurrence, position information is injected via sinusoidal positional encodings added to the input embeddings:

\[PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)\]

Large Language Models (LLMs)

LLMs are Transformer-based models trained on massive text corpora to predict the next token. They scale the Transformer architecture to billions of parameters. Key variants:

  • GPT (Generative Pre-trained Transformer): Uses only the decoder stack. Trained autoregressively (predicts next token). Used for text generation, conversation, code generation.
  • BERT (Bidirectional Encoder Representations from Transformers): Uses only the encoder stack. Pre-trained with masked language modelling (predicting masked tokens). Used for classification, NER, question answering.

Applications

  • Machine Translation: The original Transformer use-case; outperformed all RNN-based models.
  • Text Generation & Summarisation: GPT models generate coherent, contextual text.
  • Computer Vision: Vision Transformers (ViT) apply self-attention to image patches for image classification.
  • Speech Recognition: Whisper and other models use Transformer architectures for ASR.
  • Code Generation: Models like Codex generate code from natural language descriptions.
  • Multimodal Tasks: Models combining vision and language (image captioning, visual QA).
